# Raluek — Discovery Overview

## What Raluek is

Custom greeting cards paired with a gemstone, sold as a gift product line ("Mongkol"). Market: Thailand. Customer contact/ordering happens over Line, IG, FB, TikTok as much as on the website.

Source material: the founders' "Raluek MVP" note, covering four areas — Product, Operation, Internal Tool, Client Website. This discovery phase scopes **only the v1 client website** (note section 4); the other three areas (product sourcing, operations/accounting, internal tooling) are tracked in the note but not being built yet.

## v1 scope decision (2026-09-28)

Chosen over two other options (guided order flow with predefined combos; full interactive builder with live stone stock and card preview):

- Marketing/informational site + a manual order form.
- Order form output: reference code, customer + card + stone-preference details, PDPA consent — routed to a spreadsheet, fulfilled by a human over chat.
- No live stock/pricing, no live card-preview builder, no order-tracking-by-reference-code page, no internal admin dashboard.

Rationale: validate demand and real order patterns before investing in the automation the full note describes.

## Explicitly deferred (from the original note, not in v1)

- Note 4.a.iv.2–3: stone suggestion engine, real-time stock/price, live card customization/preview, template filtering.
- Note 4.b: order tracking by reference code.
- Note 3: internal order/stock admin tool.
- Note 2, 5: operations, accounting, supplier/stock management — business processes, not website scope.
