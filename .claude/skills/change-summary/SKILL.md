# Change Summary

After a batch of edits in this repo:

1. List what changed, grouped by file, one line each — the decision or content added, not a line-by-line diff.
2. Flag anything that contradicts or supersedes something written earlier in `docs/` — name the file and the prior claim.
3. Flag anything left open or assumed rather than confirmed by the user.
4. If `docs/discovery/requirements-checklist.md` exists, note any items this session's changes should check off or add.
5. Keep it under ~10 lines. Point at file:section instead of restating content.
